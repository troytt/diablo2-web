## TS fixes applied from this sweep

- Shared bit-exact `mulDiv113c` (`src/common/data/mul-div-113c.ts`, D2Common 0x6FD511E0 = D2Game 0x6FC214D0: divide-first shortcuts, low-dword 64-bit path); `combat-pipeline.ts` re-exports it.
- Absorb: `applyElementalAbsorb113c` passes `(pct, damage)` in the original register order (0x6FCFAD2A..0x6FCFAD40).
- Resist step: `applyResist113c` = `mulDiv(100 - min(res, 100), dmg, 100)` (0x6FCFBD45..0x6FCFBD6A) at every TS call site.
- Frame-rate scaled DR/MDR: `mulDiv(rate, dr256, 0x400)` (0x6FCFC13B..0x6FCFC177).
- DR overflow: a physical channel driven below 0 by DR lowers the signed total (0x6FCFC4F7..0x6FCFC519).
- Skill synergy / mastery / ELenSym: `v + mulDiv(pct, v, 100)` in calc-ast and `evaluateSkillCore113c` (0x6FDA0524, 0x6FDA041D, 0x6FDBB40F, 0x6FDA20D6, 0x6FD9E9EC, 0x6FD9F8DA).
- SkillCalc `mana` / `usmc`: no minmana floor, raw level (0x6FDA1264 / 0x6FDA1507).
- Experience: level-difference scaling through mulDiv (0x6FCFAA40, `edx = exp`), ExpRatio overflow guard (0x6FCFAA04..0x6FCFAA2C), `item_addexperience` through mulDiv (0x6FCFC090), Experience.txt row 99 ExpRatio parsed.
- Player AnimData clips generated from AnimData.D2 (`src/baker/extract/gen-char-anim-clips-113c.ts` -> `char-anim-clips-113c.generated.ts`); `CHAR_ANIM_CLIPS_113C` = HTH records, `CHAR_WCLASS_ANIM_CLIPS_113C` = every existing weapon class, so the weapon-class fallback of `getCharAnimClip113c` only applies to COFs that do not exist.
