# P5.2 Save-driven Combat / Buff Scenarios

All saves are produced **by the original game** (no hand-edited bytes):

1. `tools/oracle/create-char.py <class>` drives the original character-creation UI → level-1 save.
2. `tools/oracle/author-save.py <spec>` loads it, raises experience with the oracle `setexp` op
   (original `PLAYER_LevelUp` `0x6FD0B090`), spends points with genuine C2S `0x3B AddSkill` /
   `0x3A AddStat` packets (the server enforces prerequisites and level requirements), optionally
   unequips starter gear with genuine C2S `0x1C UnequipItem` and equips deterministic unique/set
   pieces via the authoring-only `equip` op (original `D2GAME_CreateItemEx` `0x6FC31490` +
   `ITEMS_EquipOnBody` `0x6FCF60D0`, gated strictly on authoring runs so normal scenario traces are
   untouched), and saves through the in-game *Save and Exit* menu. Specs:
   `tests/fixtures/oracle/saves/specs/*.json`.

Scenarios are generated by `tools/oracle/make-p52-scenarios.py` (seed 12345 → identical map and
route out of the Rogue Encampment for every class; first Blood Moor zombies are units 9/10/11).
Every oracle scenario was run twice and produced byte-identical traces; goldens live in
`tests/fixtures/oracle/golden/*.oracle.ndjson.gz` and are checked by
`tests/oracle/golden-parity.test.ts` (ratchet, baseline `parity-baseline.json`).

## Replica parity status (`tools/oracle/parity-report.ts`, milestone M23 closeout)

8 of 13 golden scenarios match at full length. 18,043 of 21,050 frames match overall (85.7%).

| Scenario | Frames matched | First divergence and cause |
|---|---|---|
| `p52-amazon-defense` | 1225 / 1800 | F1226 zombie #10 mode. At F1206 the player seed draws 4 on a missed swing; the source is unknown (a miss is 1 draw in `0x6FCFDE90`) |
| `p52-amazon-valkyrie` | 989 / 1500 | F990 Valkyrie y off by one subtile, after an extra pet-seed draw at F988. NecroPet `PetMove` state 1 (`0x6FC3CAE0`) is not ported |
| `p52-barbarian-warcries` | 1104 / 1600 | F1105 player y off by one subtile on the run path. Velocity stats match (67 = 150 / 68 = 100) |
| `p52-necromancer-curses` | 1516 / 2000 | F1517 skeleton #14 max HP: 757.5 in the oracle vs 757.0. Skeleton init `0x6FC6EB50` → `0x6FC6E960` is not ported (it also draws on the owner seed). The corpse removal on raise is ported |
| `p52-necromancer-poison-golem` | 859 / 1800 | F860 Poison Nova missile hits stationary zombie #10 one frame early in the replica |

The remaining 8 scenarios match at full length: `a1-town-walk`, `a1-bloodmoor-melee`, `p52-dot-ticks`,
`p52-item-defense`, `p52-paladin-auras`, `p52-paladin-merc-aura`, `p52-sorceress-elemental` and
